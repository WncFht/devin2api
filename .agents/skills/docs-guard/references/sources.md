## AI 生成文档缺陷的研究

- Kabir et al., "Is Stack Overflow Obsolete? An Empirical Study of the Characteristics of ChatGPT Answers to Stack Overflow Questions", CHI 2024——52% 的回答含错误信息；评审者 39% 的时候漏掉 AI 错误：https://dl.acm.org/doi/10.1145/3613904.3642596
- CloudAPIBench, "On Mitigating Code LLM Hallucinations with API Documentation"（AWS, 2024）——低频 API 的正确调用率 38.58%：https://arxiv.org/abs/2407.09726
- De-Hallucinator（2024）——LLM 经常编造不存在的 API；项目 API 接地修复了 63.2% 由幻觉导致的失败：https://arxiv.org/abs/2401.01701
- Spracklen et al., "We Have a Package for You!"（USENIX Security 2025）——包名幻觉在 16 个模型上平均 19.6%：https://www.usenix.org/conference/usenixsecurity25/presentation/spracklen
